# PHP Words

Proyecto de ejemplo para la tarea de **Despliegue de Aplicaciones Web**.

Lista palabras reservadas de PHP en una página estática que funciona en local.

## Estructura

```
php-words/
├── index.html
├── README.md
├── css/
│   └── estilos.css
└── js/
    ├── config.js
    ├── palabras.js
    └── app.js
```

## Cómo abrirlo

Abrir index.html en el navegador (doble clic).

Requiere un navegador moderno.
